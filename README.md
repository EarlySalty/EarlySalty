## Über mich

Hey, ich bin **Nani**, auf GitHub **EarlySalty**. Ich baue und betreibe die **Deutsche Deadlock Community**: Discord, Twitch, Steam, Website und Turniere. Ein Server, die Dienste dahinter, und der Mensch der nachts rangeht wenn etwas ausfällt.

Seit August 2025 läuft das als eigenes System auf einem Root-Server. Rust in Produktion, PostgreSQL als Speicher, KI-Agenten für den Betrieb.

- Discord-Bot: Onboarding, Rollen, Steam-Verifikation, Voice-Router
- Twitch-Bot mit Selfservice-Dashboard, Streamer richten ihn selbst ein
- Steam-Dienste für Profil- und Match-Abgleich
- Website, Docs und Turniere für die Community
- KI-Agenten, die den Betrieb im Blick halten
